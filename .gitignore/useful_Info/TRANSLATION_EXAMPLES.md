## 🔄 Switching Languages

To switch between languages, simply change the `language` config parameter:

```javascript
// Scottish Gaelic
config: { language: "gd", locale: "gd-GB" }

// Irish Gaelic
config: { language: "ga", locale: "ga-IE" }

// English
config: { language: "en", locale: "en-GB" }

// Spanish
config: { language: "es", locale: "es-ES" }

// French
config: { language: "fr", locale: "fr-FR" }

// German
config: { language: "de", locale: "de-DE" }

// Italian
config: { language: "it", locale: "it-IT" }

// Dutch
config: { language: "nl", locale: "nl-NL" }

// Portuguese
config: { language: "pt", locale: "pt-PT" }
```

**Note**: The `locale` parameter controls date/time formatting, while `language` controls UI text.

---

## 📝 Notes

1. **Team names** (e.g., "Celtic", "Rangers") are NOT translated - they are proper nouns
2. **Competition names** from the API are NOT translated - they come from TheSportsDB
3. **Opponent names** are NOT translated - they are proper nouns
4. **Date/time formatting** is controlled by the `locale` parameter, not `language`
5. All **UI labels and messages** are fully translated
